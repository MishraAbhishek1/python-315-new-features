# Python 3.15 — New Features Explained with Examples 🐍

I'm exploring the new features introduced in Python 3.15 by building small, practical Python programs.

The goal is to understand what changed, why it matters, and how these features may help in real-world backend development.

## 🚀 Features I'm Exploring

| Feature | What I'm Learning |
|---|---|
| `frozendict` | Creating immutable mappings |
| Lazy Imports | Delaying module loading until needed |
| Sentinel Values | Distinguishing a missing value from `None` |
| Unicode Graphemes | Working with user-perceived characters |
| Profiling | Investigating function execution time |
| Unpacking in Comprehensions | Transforming iterable data |
| UTF-8 Encoding | Handling text consistently across platforms |
